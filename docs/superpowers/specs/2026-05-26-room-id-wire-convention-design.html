1 · Context

A max-effort code review of feat/room-group-scope-refactor surfaced four findings that share a single root cause: the server has not decided what room_id means on the wire.

#FileSymptom
1 src/zndraw_joblib/router.py:370 + 7 sibling sites Emits to room:<composed>; subscribers joined room:<surrogate>. Tools panel, providers list, task-progress UI stay stale.
2 src/zndraw/routes/frames.py:524 FramesInvalidate.room_id = room.id (surrogate); frontend keys cache by composed address; predicate never matches.
3 src/zndraw/client/socket.py:148 event.room_id != self.zndraw.room compares surrogate to composed; pyclient cached_length never refreshes.
14 src/zndraw/routes/rooms.py:711 RoomRenamed emitted only to room_channel(room.id); previous owner's rooms list never reconciles.

The existing code is split: SessionJoined, SessionLeft, and RoomJoinResponse use room.public_address; Typing, FramesInvalidate, FrameUpdate, and joblib events use room.id. There is no single convention that the four findings violate — only an absence of one.

2 · Decision

Adopt the GitHub/GitLab/Slack pattern.

  • Channels are surrogate UUIDs. Socket.IO room names are always f"room:{room.id}". Channels survive renames and ownership transfers without resubscription.
  • Payloads carry both ids. Every room-scoped event has room_id: UUID (stable identity, cache key, channel key) and room_address: str (composed <owner>/<name>, display, URL).
  • Joblib persistence uses the surrogate. Job.room_id and ProviderRecord.room_id store the surrogate UUID going forward, not the composed string. Ownership transfer no longer strands rows.

3 · Invariants

  1. Every Pydantic event model representing a room-scoped event inherits from RoomScopedEvent and declares both room_id: UUID and room_address: str as required fields.
  2. Every emit of a RoomScopedEvent instance goes through broadcast_to_room. Sigil-scoped and user-scoped emits do not inherit the mixin and continue to call sio.emit directly.
  3. The Socket.IO channel name for a real (non-sigil) room is exactly f"room:{room.id}".
  4. RoomScopedEvent.for_room(room, **kw) is the only blessed constructor; manual construction with one of the two ids missing fails Pydantic validation at the call site.
  5. Joblib Job.room_id and ProviderRecord.room_id values are either str(UUID) (surrogate) or a sigil (@global, @internal). get_writable_room_id returns the surrogate UUID string for real rooms.
  6. Ownership transfers emit RoomRenamed to room_channel(room.id) AND to user:<previous_owner_user_id>. The previous owner's rooms list reconciles without polling.

4 · Non-goals

  • Backwards compatibility. The PR already requires fresh database recreation; this spec does not provide migration code for existing composed-form Job.room_id rows.
  • Family 2 (share-token plumbing — findings #4, #5, #6) and Family 3 (authorization & validation — findings #7–#13, #15). Each has its own spec.
  • Frontend test scaffolding. The repo has no vitest layer; adding one is tracked as a follow-up.
  • Changing URL paths or the composed-address public API.

async def broadcast_to_room(sio, event, room, *, also_notify_user=None):
    await sio.emit(event, room=room_channel(room.id))
    if also_notify_user is not None:
        await sio.emit(event, room=f"user:{also_notify_user}")

Sigil channels (@global, @internal)

Sigil rooms have no Room row and no public_address. Their events do not inherit RoomScopedEvent. Emit sites continue to call sio.emit(event, room=f"room:{sigil}") directly. The contract test whitelists sigil channels.

8 · Testing strategy

Three layers, six new test files.

Layer 1 — static schema audit ~30 lines

tests/zndraw/test_event_schema_audit.py. Walks RoomScopedEvent.__subclasses__() and asserts each subclass declares both fields with the right types. Runs in milliseconds. Marked @pytest.mark.protected. 

def test_all_room_scoped_events_have_both_ids() -> None:
    for cls in _all_subclasses(RoomScopedEvent):
        fields = cls.model_fields
        assert "room_id" in fields, f"{cls.__name__} missing room_id"
        assert "room_address" in fields, f"{cls.__name__} missing room_address"
        assert fields["room_id"].annotation is UUID

Layer 2 — runtime contract test ~250 lines

tests/zndraw/test_broadcast_contract.py. Uses server_factory; a fixture monkey-patches sio.emit to capture every (event, channel) tuple. A parametrized matrix drives the server through one representative action per event family (frame append, geometry put, bookmark post, chat send, typing, session join, room update, room rename, joblib job register, joblib provider register, joblib task status change, joblib provider result upload). For each captured event the test asserts:

  • event.room_id == room.id (UUID)
  • event.room_address == room.public_address (composed)
  • channel == f"room:{room.id}"

Plus a final sweep assertion iterating every captured tuple and asserting the channel format invariant for every captured RoomScopedEvent. Marked @pytest.mark.protected.
