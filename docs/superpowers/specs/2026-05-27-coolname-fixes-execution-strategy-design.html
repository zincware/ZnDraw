Surprise protocol

Pause triggers — I stop and report:

  1. Architectural rethink needed (B3 signature change > 10 LOC; B6 needs new sync primitive).
  2. Schema migration becomes unavoidable (D8 grows a Group.slug column).
  3. Protected test still red after B3 fix — invariant genuinely shifted, needs sign-off.
  4. A test refuses to pass after 2 fix attempts.
  5. Any task touches > 5 files outside its declared scope.
  6. Destructive action needed (force push, branch delete, rewriting shared history).

No-pause cases (continue):

  • Tests pass on first try.
  • Subagent reports cleanly.
  • prek auto-fix reformats files.
  • Mechanical fixture fixes land green.

Pause output format (≤ 200 words):

  • What surprise, what I tried, options I see, explicit ask.
  • Branch state (commits landed, tests green, tests still red).
  • No destructive recovery while waiting — preserve for inspection.

Subagent contract

Every dispatched agent's prompt contains:

  • Plan ref: docs/superpowers/plans/2026-05-27-coolname-display-names-fixes.md + task ID (e.g., "Task A1") with verbatim file:line targets.
  • Exact CI failure(s) the task resolves, including the error message — verification by error-match.
  • Working dir, branch (already on worktree-coolname-display-names).
  • Reporting: ≤ 150-word summary — paths touched, test commands, pytest output for targeted tests.

Hard constraints baked in:

  • No file edits outside the declared file list (else SURPRISE).
  • No @pytest.mark.protected edits.
  • No --no-verify, no --amend, no force ops.
  • Targeted pytest only; no full-suite run inside the subagent.

Concurrency safety:

  • Phase A's 6 tasks touch disjoint test files — safe fan-out.
  • Phase D's waves grouped by shared-file risk; conflicts resolved by rebase, not destructive cleanup.
  • I retain control of all Phase B / C / E / F (shared modules, cross-stack, judgment calls).
